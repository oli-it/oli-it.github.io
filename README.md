# Marquis Olinick: IT Support Home Lab

Live site: https://oli-it.github.io

A portfolio of troubleshooting tickets I work in my own virtual lab (VirtualBox, Windows 11, Windows Server 2022). Each ticket covers the user's complaint, how I investigated, the fix, and how I verified it, with screenshots as evidence.

Practice scenarios are planted by an AI lab tutor without telling me the cause. I diagnose and fix them myself, and each ticket notes how much help I needed.
